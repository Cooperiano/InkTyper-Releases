# InkTyper Support

Before opening an issue:

1. Confirm the installed InkTyper version.
2. Check the SHA-256 checksum of the installer.
3. Restart InkTyper once from the desktop application menu.
4. Search existing issues for the same Linux distribution and desktop environment.

When reporting a bug, include your distribution, desktop environment, display session (X11 or Wayland), installation format (`.deb` or AppImage), and clear reproduction steps. Do not attach account tokens, private transcripts, cookies, or credential files.
