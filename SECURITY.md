# Security Policy

Please do not disclose vulnerabilities, access tokens, account details, private transcripts, or other sensitive data in a public issue.

Report a vulnerability privately through [GitHub Security Advisories](https://github.com/Cooperiano/InkTyper-Releases/security/advisories/new). Include the InkTyper version, operating system, expected behavior, observed behavior, and the smallest safe reproduction you can provide.

For non-security bugs and installation questions, use the public issue templates instead.
