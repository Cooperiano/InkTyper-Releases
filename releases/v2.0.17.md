## InkTyper 2.0.17 for Linux

This release brings the Linux desktop client up to date with InkTyper's tray-first workflow.

### Highlights

- Native system-tray controls and global `Ctrl+Shift+Space` shortcut.
- Account-scoped History synchronization: final text only, 30-day / 500-item retention, with deletion propagation.
- Encrypted local login cache now survives restarts and temporary network unavailability; only an explicit unauthorized response clears it.
- Dark integrated Linux title bar with native minimize, maximize, and close controls.
- Debian / Ubuntu package and portable AppImage for x86_64 systems.
